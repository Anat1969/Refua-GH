# רפואה: גוף, מחלה, בריאות

**[לאפליקציה החיה: refua-gh.vercel.app](https://refua-gh.vercel.app/)**

המיזוג האחרון, בלי Vercel: https://raw.githack.com/Anat1969/Refua-GH/main/index.html

כל מערכת בגוף: תפקיד, כשל, וסימן לפנייה.
כל פריט מסומן בשכבה אחת: ידוע, נאמר, מאמינים.

לא מאגר. לא ספר. לא אבחון.
כלי שמלמד לקרוא את הגוף ואת המידע עליו: מה זה, מה משבש, מתי פונים, ומה נשאר לא ידוע.

## עקרונות
1. פחות מילים, יותר מבנה.
2. כל דבר נראה לפני שהוא נקרא: דמות, שקף, סכמה.
3. שלוש שכבות בלבד בכל פריט: ידוע, נאמר, מאמינים.
4. אין ייעוץ רפואי, אין אבחון, אין מינונים.
5. כל טענה מתועדת. מה שלא נבדק מסומן כך.

## אפליקציה אחות
אפליקציית התזונה ("מזון, גוף ונפש"). כל מערכת כאן מחזיקה גשר לפריט מזון או לנושא תזונתי שם. החוזה: docs/DATA_MODEL.md, סעיף "גשר".

## הרצה
```bash
python3 -m http.server 8765
```
```bash

```
```bash
node tests/e2e.cjs
```

## מבנה
- `index.html`: המסך.
- `css/app.css`: אסימוני DNA ושפת העיצוב.
- `js/data.js`: מקור הנתונים היחיד, כולל המקורות.
- `js/body.js`: הדמות ושקפי המערכות.
- `js/app.js`: ניתוב בכתובת, כרטיס מערכת, סימני חירום, מקורות.
- `scripts/check-safety.mjs`: שער בטיחות לפני מיזוג.
- `tests/e2e.cjs`: בדיקת קצה לקצה בארבעה גדלי מסך.
- `reference/`: אב הטיפוס של אפליקציית התזונה, לעיון.

## מסמכים
- CLAUDE.md: הוראות לקלוד קוד (קרא ראשון)
- docs/SPEC.md: מה בונים ולמה
- docs/SAFETY.md: כללי בטיחות (חובה לפני כל תוכן)
- docs/CONTENT_RULES.md: חוקי ניסוח
- docs/DATA_MODEL.md: מבנה הנתונים והגשר לתזונה
- docs/SOURCES.md: מקורות
- docs/ROADMAP.md: שלבי בנייה
- docs/VISUAL.md: שפה ויזואלית
